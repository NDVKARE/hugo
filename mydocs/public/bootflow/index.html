    Khái niệm tổng quát

    PMU - (Platform Management Unit – khối quản lý nền tảng) quản lý các trạng thái nguồn nội bộ của SoC bằng phần cứng power-control nằm ngay trong SoC.
    │
    ├────► Full-Power Domain
    ├────► Low-Power Domain
    ├────► clock
    ├────► reset
    └────► isolation

    CSU - (Control and Security Unit - khối điều khiển và bảo mật) thực hiện các chức năng boot và bảo mật của SoC
    │
    ├────► boot controller, boot ROM
    ├────► DMA (Direct Memory Access – truy cập bộ nhớ trực tiếp)
    ├────► SHA (Secure Hash Algorithm – thuật toán băm bảo mật)
    ├────► AES (Advanced Encryption Standard – chuẩn mã hóa nâng cao)
    ├────► Public-key verification như RSA hoặc ECC (Elliptic Curve Cryptography – mật mã đường cong elliptic) ├────► Key storage/eFuse, anti-rollback counter
    ├────► Đọc boot source như QSPI, eMMC, SD hoặc SPI NOR
    └────► Secure boot state machine

    FSBL - (First Stage Boot Loader - bộ nạp khởi động giai đoạn đầu) khởi tạo DDR, chuẩn bị nền tảng và phối hợp CSU xác thực các image trước khi chuyển quyền cho OpenSBI.
    │
    ├────► load OpenSBI ─► handoff to OpenSBI
    └────► Load U-boot

    OpenSBI - (Open Source Supervisor Binary Interface - firmware cung cấp SBI) chạy ở M-mode, cung cấp dịch vụ nền tảng cho phần mềm S-mode và chuyển quyền cho U-Boot.
    │
    ├────► SBI interface
    └────► handoff to U-boot

    U-Boot - (Universal Boot Loader - bộ nạp khởi động) nạp Linux kernel, device tree và initramfs, chuẩn bị tham số boot rồi chuyển quyền cho kernel.
    │
    ├────► load Linux kernel, initramfs, device tree
    └────► Boot to linux

    Linux - (Hệ điều hành Linux) khởi tạo driver, mount rootfs và chạy các dịch vụ, ứng dụng của hệ thống.
    │
    └────► run Application

    RPU - (Real-Time Processing Unit - khối xử lý thời gian thực) thực thi firmware hoặc RTOS cho các tác vụ điều khiển cần đáp ứng thời gian thực.
    │
    └────► run Realtime function
